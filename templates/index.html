Application de démonstration SQL Injection

Une application Flask + SQLite fonctionnelle (catalogue de produits, comptes, recherche et administration) conçue pour observer le comportement des requêtes SQL et comparer une implémentation volontairement vulnérable à sa version paramétrée et sécurisée.

Accéder à l’application

Recherche GET

/search?q= interroge le catalogue selon une recherche texte ; /product?id= affiche la fiche d’un produit par identifiant.

Recherche POST

/login et /search-post traitent des corps de formulaires pour illustrer la différence entre les méthodes HTTP.

Comparaison

Les routes *-safe, la zone /admin et le code source montrent les implémentations paramétrées et les contrôles d’autorisation recommandés.

Comptes de départ

alice / alice123 (user), bob / bob123 (user), analyst / observe123 et admin / admin123.

Utilisation responsable : cette application est volontairement vulnérable et doit uniquement être exécutée en local sur http://127.0.0.1:5000. Ne l’exposez jamais sur un réseau, une adresse LAN ou Internet.
